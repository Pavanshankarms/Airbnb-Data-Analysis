# Airbnb-Data-Analysis
Airbnb Hotel Booking Data Analysis project using Python, Pandas, NumPy, Matplotlib, and Seaborn. Includes data cleaning, EDA, visualization, and insights.

# Airbnb Data Analysis Project

## 📌 Project Overview
This project analyzes Airbnb hotel booking data to extract meaningful insights using Python.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🔍 Key Steps Performed
- Data Cleaning
- Handling Missing Values
- Removing Duplicates
- Outlier Detection & Removal (IQR Method)
- Exploratory Data Analysis (EDA)
- Data Visualization

## 📊 Key Insights
- Identified booking trends
- Analyzed pricing distribution
- Detected outliers in Total Bill
- Found patterns in customer behavior

## 📁 Project Structure
- `analysis.ipynb` → Main analysis notebook
- `scripts/` → Data processing scripts
- `requirements.txt` → Libraries used

## 🚀 Conclusion
This project demonstrates end-to-end data analysis including cleaning, transformation, and visualization.
